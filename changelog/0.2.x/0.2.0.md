# 0.2.0 — 2026-10-20

## Added

- **`datamuse_get_word_info`** returns metadata on supplied words and phrases, with indexed partial outcomes and a shared 20-second deadline ([#5](https://github.com/cyanheads/datamuse-mcp-server/issues/5)).
- **Pronunciation options** request raw ARPAbet or IPA metadata across search and lookup tools ([#6](https://github.com/cyanheads/datamuse-mcp-server/issues/6)).

## Changed

- **Search responses** select whole rows under 64,000 bytes per serialized surface, with best-effort offsets and an explicitly disclosed intact oversized-row exception ([#3](https://github.com/cyanheads/datamuse-mcp-server/issues/3)).
- **Spelling guidance** documents upstream anagrams, vowel/consonant patterns, and letter restrictions ([#4](https://github.com/cyanheads/datamuse-mcp-server/issues/4)).
- **Documentation and discovery** describe the five-tool surface, refresh package keywords, and remove unsupported framework settings from the environment example.

## Fixed

- **Empty phrase relations** explain limited coverage and suggest meaning, sound, or final-word rhyme alternatives while retaining accepted phrase inputs ([#2](https://github.com/cyanheads/datamuse-mcp-server/issues/2)).
