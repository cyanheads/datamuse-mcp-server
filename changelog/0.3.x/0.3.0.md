# 0.3.0 — 2026-11-21

## Added

- **Spanish word lookup.** Set `vocabulary: "es"` in `datamuse_get_word_info` to look up a batch in Spanish. Both response surfaces include the resolved vocabulary. ([#9](https://github.com/cyanheads/datamuse-mcp-server/issues/9))
- Serve the Datamuse search guide as an MCP resource at `skill://datamuse-guide/SKILL.md`. The guide covers constrained searches, rhyme fallbacks, and partial lookups.
- **Agent plugin manifest.** Install the server using an Agent Plugins-compatible host.

## Fixed

- **Frequency and spelling guidance.** The lookup and metadata reference explain query echoes, spelling suggestions, and the difference between a reported zero and an omitted frequency tag. ([#10](https://github.com/cyanheads/datamuse-mcp-server/issues/10))
- **Local pacing errors.** Search errors explain why the local request slot could not open and surface the retry delay on both MCP response surfaces. ([#11](https://github.com/cyanheads/datamuse-mcp-server/issues/11))
- **Datamuse API key transition.** The documented start date is February 1, 2027.
