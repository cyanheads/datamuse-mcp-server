# 0.1.1 — 2026-10-19

## Added

- **`datamuse_find_rhymes`** finds exact or near English rhymes with optional meaning and spelling constraints.
- **`datamuse_find_synonyms`** finds synonyms, antonyms, broader categories, and narrower kinds.
- **`datamuse_find_words`** combines meaning, sound, spelling, and named lexical relations, with context and topic hints; English and Spanish support follows Datamuse's relation limits.
- **`datamuse_list_reference`** provides offline relation, metadata, query-combination, and access guidance.
- **Search results** preserve upstream order, sparse metadata, definitions, and additional JSON fields on both output surfaces, with effective queries and honest empty-result and result-cap guidance.
- **Datamuse requests** share process-local pacing, a bounded queue, and bounded retries; current access is keyless and may change under the provider's announced 2027 transition.
- **Installation** supports stdio and Streamable HTTP, npm, Claude Desktop bundles, container images, and Claude Code and Codex plugins.
